# ohms-razor

Never use more model than the task needs.

The solved economics of inference placement: what belongs on a local always-on box, what
goes to a cheap high-volume API tier, and what goes to a frontier API tier. An always-on
local box is where an agent lives; it is not where thinking happens. Hosting and inference
are different workloads with different economics, and conflating them is how people buy the
wrong hardware.

Full build is landing via PR. The data layer, models, tests, analysis, and the solved
README arrive there.
